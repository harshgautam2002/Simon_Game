# 🎮 Simon Game

## 🧠 How It Works
1. **Start the Game:** Press any key on your keyboard to begin.
2. **Watch the Pattern:** The game will flash a button and play a sound.
3. **Repeat the Pattern:** Click the buttons in the exact sequence shown.
4. **Level Up:** Every time you successfully clear a round, the game adds one more step to the sequence, speeding up the challenge!
5. **Game Over:** If you click the wrong button, it's game over. Press any key to reset and try to beat your high score.

---

## ✨ Features
* 🎵 **Audio-Visual Feedback:** Distinct sounds and flash animations for each of the 4 colorful buttons.
* 📈 **Progressive Difficulty:** Dynamic sequence tracking that gets longer with each level.
* 📱 **Responsive Design:** Optimized to play smoothly across different desktop screen sizes.
* 💥 **Game-Over State:** Dramatic visual shake/flash effect and an error sound when you lose.

---

## 🛠️ Tech Stack
This project was built using purely frontend technologies to ensure fast loading times and smooth animations:

* **HTML5:** Structuring the game board grid and buttons.
* **CSS3:** Custom styling, layouts, and button press animations.
* **JavaScript (ES6):** Game logic, state management, event listeners, and DOM manipulation.
